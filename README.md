# Afiza Rafiqui

Personal website for Afiza Rafiqui.

## Publish with GitHub Pages

1. Upload everything in this folder to the root of your repository.
2. In the repository, go to Settings, then Pages.
3. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Files

- `index.html`: the whole site (styles and scripts included)
- `*.jpg`, `*.mp4`: photos and videos used on the page
